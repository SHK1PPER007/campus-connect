# Научная работа: Campus.Connect

Билингвальная веб-платформа для академической и социальной адаптации иностранных студентов, разработанная в рамках научной работы по теме сотрудничества Беларуси и Китая.

Дизайн пользовательского интерфейса и вся клиентская и серверная логика (компоненты, типы данных, моковые сервисы, алгоритмы модерации и API-интеграции) разработаны с нуля.

## Стек технологий

- TypeScript, React 18
- Vite
- Tailwind CSS
- TanStack Query (React Query)
- Lucide React
- Zod

## Структура проекта

- `src/`
  - `components/` — интерфейсные модули:
    - `Navbar.tsx`, `Sidebar.tsx` — навигация и переключение локали.
    - `PostCard.tsx`, `CommentSection.tsx`, `CreatePostModal.tsx` — лента публикаций, ветки комментариев, создание постов.
    - `CampusMapModal.tsx` — интерактивная карта кампуса, общежитий и учебных корпусов.
    - `GlossaryModal.tsx` — двуязычный студенческий словарь терминов.
    - `WikiKnowledgeBase.tsx` — база знаний по процедурам регистрации, визам, быту и учебе.
    - `BelarusQuizModal.tsx`, `CultureTipWidget.tsx` — интерактивные модули знакомства с культурой и правилами.
    - `AdminPanel.tsx` — панель администрирования пользователей, жалоб и контента.
    - `ProfileDashboard.tsx` — профиль пользователя и настройки.
  - `services/` — интеграции и бизнес-логика:
    - `postsApi.ts` — API управления постами, фильтрация по категориям и тегам.
    - `aiServices.ts` — модуль интеграции с нейросетевыми сервисами (перевод, суммаризация, ответы на вопросы).
    - `moderationService.ts` — автоматическая проверка и фильтрация недопустимого контента.
    - `speechUtils.ts` — синтез речи для озвучивания терминов и подсказок.
  - `types/` — строгая типизация сущностей (схемы постов, пользователей, категорий).
  - `mock/` — тестовый массив данных для автономной работы приложения.

## Основной функционал

- Двуязычный интерфейс (русский / китайский) с мгновенным переключением.
- Тематическая лента публикаций: Учеба, Быт, Жилье, Бюрократия, Мероприятия, Барахолка.
- Интерактивная карта ключевых локаций университета и города.
- Русско-китайский справочник студенческой терминологии с аудиопроизношением.
- База знаний с пошаговыми инструкциями по оформлению документов.
- Интеграция с языковыми моделями для контекстного перевода и консультаций.
- Модуль модерации контента и панель администратора.

## Установка и запуск

1. Установка зависимостей:
```bash
npm install
```

2. Настройка переменных окружения:
Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```
При необходимости укажите API-ключ Hugging Face / LLM:
```env
VITE_HF_API_KEY=your_token_here
```

3. Запуск в режиме разработки:
```bash
npm run dev
```

4. Сборка production-бандла:
```bash
npm run build
```
